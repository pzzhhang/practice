# Epic Eye X 3D 工业相机用户指南

## 1. 产品简介

Epic Eye X 是迁移科技 Epic Eye 系列 3D
工业相机之一，可用于工业视觉场景中的三维数据采集。相机通过千兆以太网与工控机等设备连接，并采用固定安装方式。

本指南介绍产品安全注意事项、主要技术规格、安装与连接，以及日常维护要求。

## 2. 安全须知

使用相机前，请阅读并理解产品手册中的安全说明。

- 避免在多尘、强电磁干扰、强光直射或超出规定温湿度范围的环境中使用相机。
- 相机工作期间，请勿直视投影光束。
- 保持相机窗口清洁；清洁时使用无尘布。
- **严禁在相机通电状态下进行安装、拆卸或清洁。**
- 运输和安装过程中，应避免相机受到剧烈碰撞或跌落。
- 如发现异响、异味、冒烟等异常情况，应立即切断电源并进行检查。
- 严禁改装相机或其配套电源线。

> **警告：**
> 未按安全规范操作可能导致设备损坏或人身伤害。执行安装、连接和维护操作前，应先确认设备处于断电状态。

## 4. 开箱检查

收到设备后，请按以下步骤检查：

1. 检查相机及配件是否存在损坏、锈蚀、碰伤等情况。
2. 对照随箱包装清单核对物料是否齐全。
3. 如果发现设备损坏或物料缺失，请联系迁移科技获取支持。
4. 安装前确认相机型号与项目选型一致。

## 5. 安装与连接

### 5.1 安装相机

安装时建议遵循以下原则：

- 将相机安装在目标区域的合适位置，确保相机视野内没有遮挡物。
- 尽量使相机底面与目标作业平面保持平行。
- 确保安装结构牢固，避免设备在运行过程中发生位移或振动。
- 安装位置应满足产品规定的工作距离和环境要求。

具体安装孔位、尺寸及结构要求，请参考对应版本的官方外形尺寸图。

### 5.2 连接线缆

连接前请注意：

- **请勿带电插拔线缆。**
- 先完成所有线缆连接，再接通电源。
- 对准插头与插孔后缓慢插入并固定，避免用力扭转或强行拔插。
- 建议使用扎带固定网线、电源适配器和电源线，避免线缆松脱。
- 如果通过路由器连接设备，请将相关网线连接至路由器的 LAN 端口。

相机可根据现场网络结构与工控机直接连接，也可通过路由器连接。实际连接方式应遵循项目网络设计和官方接线说明。

## 6. 基本使用流程

以下为设备部署的通用检查顺序，具体软件操作请参照对应版本的 Epic Eye
软件手册。

1. 确认相机已正确固定。
2. 检查网线、电源线及连接器是否连接牢固。
3. 确认供电规格符合产品要求。
4. 完成线缆连接后接通电源。
5. 打开配套软件，按照软件手册连接相机。
6. 执行采集测试，并检查采集结果是否符合项目要求。

如果设备未能正常连接或采集，请先停止后续操作，并检查供电、网络连接和软件配置。

## 7. 维护与清洁

### 7.1 定期检查

定期检查以下项目：

- 相机机身是否损坏。
- 固定螺钉是否损坏或松脱。
- 电源线是否老化或破损。
- 相机窗口是否清洁。

如发现异常，请停止使用并联系技术支持，不要自行改装设备。

### 7.2 清洁相机

- 清洁机身时，使用干净的软布。
- 清洁镜头窗口时，使用蘸有镜头清洁剂或玻璃清洁剂的干净、柔软、无绒布。
- 清洁时避免划伤光学表面。
- 清洁前必须切断电源。

## 8. 故障排查

| 故障 | 建议措施 |
|------|------|
| 相机无法连接 | 检查相机供电、网络连接是否通畅   |
| 无法采集数据 | 检查相机是否连接成功，并检查软件配置和采集流程   |
| 指示灯状态异常| 检查线缆是否正常  |

----------------------------------------------------------------------------

以上为初步检查建议，不替代官方故障诊断流程。若问题仍未解决，请记录设备型号、软件版本、异常现象和复现步骤，并联系迁移科技技术支持。
